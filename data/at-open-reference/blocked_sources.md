# Blocked Sources

These sources must not be copied, scraped, summarized into a reusable corpus, or
packaged into Scout unless Hogg Country obtains written permission or finds a
specific compatible license.

- FarOut waypoint data, water reports, user comments, photos, and metadata.
- The A.T. Guide / AWOL guide mileage, town, resupply, and waypoint data.
- A.T. Data Book mileage tables and waypoint tables.
- Thru-Hikers' Companion content.
- AllTrails, Gaia GPS, and Hiking Project data or user content.
- ATC website text, maps, tables, downloads, and resources by default.
- Copyrighted/private guide PDFs and copied guidebook notes.
- Random blogs when the page appears to reproduce guidebook tables or comments.

Allowed handling: Scout may point a user to these sources as places to check, but
the pack must not ingest or redistribute their content.
