# MVP2 Virginia Live Conditions Policy

Always live-check closures, detours, fire, flooding, storm damage, bear activity, snow/ice, permit changes, road access, and dangerous weather. Use NWS for weather/alerts, NPS for Shenandoah/Blue Ridge Parkway/Harpers Ferry, USFS/GWJ for forest alerts/orders, Virginia DCR for state parks, and ATC Trail Updates as a verification pointer only. If live retrieval fails, say so and show last-checked time.
