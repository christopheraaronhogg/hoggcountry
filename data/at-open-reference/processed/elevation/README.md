# Elevation

USGS-derived elevation samples, climb/descent summaries, and grade-screening outputs belong here.

Current lanes:

- `*_5_0mi.*`: coarse 5-mile terrain summaries retained for compact overview use.
- `*_1_0mi.*`: 1-mile samples, segment summaries, profiles, high/low summaries, and conservative grade-screening candidates.

Scout must describe these as model-derived USGS 3DEP estimates sampled along the open route geometry. They are not guidebook profiles, surveyed summit values, or precise field-grade slope analysis.
