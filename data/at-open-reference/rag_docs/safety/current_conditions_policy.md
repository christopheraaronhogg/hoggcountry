# Current Conditions Policy

Scout must use live sources for weather, closures, detours, flooding, fire or
smoke, bear activity, permit changes, Baxter/Katahdin access, and other current
conditions.

Preferred live sources include NWS, NPS API alerts, USFS/state alerts, and
official land-manager pages. ATC Trail Updates may be linked or checked, but not
blindly packaged into this corpus.

If live retrieval fails, Scout must say that clearly and provide any available
last-checked timestamp.
