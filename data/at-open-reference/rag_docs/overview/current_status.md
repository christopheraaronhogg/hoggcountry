# Scout AT Open Reference Pack Status

This pack is in early generated-data setup. Scout may use these docs for
license-aware planning, generated-mile cautions, conservative water language,
coarse terrain summaries, and OSM-mapped candidate leads, but not as a complete
AT reference corpus yet.

Do not answer as if this pack contains official ATC miles, complete route truth,
verified water reliability, confirmed hiker services, current access legality,
or camping-rule data until those processed files exist and pass validation.
